MISIÓN DE PROGRAMACIÓN · PYTHON

⛏️ Banco de
Esmeraldas

¡Construí un pequeño sistema bancario inspirado en Minecraft! Administrá esmeraldas y comprá herramientas para tu aventura.

📜 Tu misión

Steve llegó a una aldea con 100 esmeraldas. Necesita un programa que le permita consultar cuántas tiene, depositar, retirar y comprar herramientas. ¡Tu trabajo es programarlo en Python!

🖥️ Así debe verse el menú

================================ BANCO DE ESMERALDAS ================================ 1. Consultar esmeraldas 2. Depositar esmeraldas 3. Retirar esmeraldas 4. Comprar herramientas 5. Ver inventario 6. Salir Seleccioná una opción:

El menú debe volver a aparecer después de cada acción, hasta que el jugador elija 6. Salir.

🧱 ¿Qué debe hacer el programa?

01Consultar

Mostrar la cantidad actual de esmeraldas.

02Depositar

Pedir una cantidad y sumarla a las esmeraldas.

03Retirar

Pedir una cantidad y restarla. Si no hay suficientes esmeraldas, mostrar un aviso.

04Comprar

Mostrar la tienda. Si alcanza el saldo, descontar el precio y guardar el objeto en el inventario.

05Inventario

Mostrar los objetos comprados recorriendo una lista.

06Salir

Mostrar un mensaje de despedida y terminar el programa.

🛒 Tienda de la aldea

⛏️ Pico20 esmeraldas
⚔️ Espada30 esmeraldas
🛡️ Armadura50 esmeraldas

Cuando Steve compra un objeto, agregalo a una lista de inventario.

✅ Reglas del desafío

  1. Steve comienza con 100 esmeraldas.
  2. No se puede retirar más de lo que hay disponible.
  3. No se puede comprar una herramienta sin suficientes esmeraldas.
  4. Si se elige una opción inexistente, el programa debe avisar.
  5. El menú debe repetirse hasta elegir Salir.

🧠 Pistas: herramientas de Python

Vas a necesitar variables para las esmeraldas, input() y print() para comunicarte con el jugador, if / elif / else para las decisiones, while para repetir el menú, y una lista con for para el inventario.

⭐ Desafío extra (opcional): evitar depósitos y retiros de cero esmeraldas o cantidades negativas.
